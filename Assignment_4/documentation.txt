# Documentation

## Data Structures

### ksocket.h
- `SOCK_KTP`: Socket type for KTP sockets.
- `T`: Timeout duration in seconds.
- `P`: Probability of message drop.

## Functions

### ksocket.c
- `int k_socket(int domain, int type, int protocol)`: Creates a KTP socket.
- `int k_bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen)`: Binds a KTP socket to an address.
- `ssize_t k_sendto(int sockfd, const void *buf, size_t len, int flags, const struct sockaddr *dest_addr, socklen_t addrlen)`: Sends a message using KTP.
- `ssize_t k_recvfrom(int sockfd, void *buf, size_t len, int flags, struct sockaddr *src_addr, socklen_t *addrlen)`: Receives a message using KTP.
- `int k_close(int sockfd)`: Closes a KTP socket.
- `int dropMessage(float p)`: Simulates message drop.

### initksocket.c
- `void *receive_thread(void *arg)`: Thread that handles receiving messages.
- `int main()`: Initializes the KTP socket and starts the receive thread.
